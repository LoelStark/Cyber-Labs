## `01 // THE MISSION`

Cybersecurity is best learned by doing.

Cyber-Labs was created to make the first steps into cybersecurity more accessible, especially for beginners who want practical experience without getting lost in complicated documentation.

The goal is simple:

- **Learn** fundamental concepts through simplified explanations.
- **Practice** through hands-on activities.
- **Explore** Linux and the building blocks of cybersecurity.
- **Experiment** at your own pace, wherever you are.
- **Build confidence** before moving on to more advanced tools and techniques.

This isn't an attempt to document every cybersecurity topic in existence. It's a starting point: practical, accessible, and straightforward.

## `04 // QUICK START`

You don't need a complicated setup to access the labs.

### Option A — Run online

1. Open the [Cyber-Labs repository](https://github.com/LoelStark/Cyber-Labs).
2. Select a lab HTML file.
3. View the file and access the available content.

### Option B — Run locally

Clone the repository:

```bash
git clone https://github.com/LoelStark/Cyber-Labs.git
```

Enter the project directory:

```bash
cd Cyber-Labs
```

Open any of the lab HTML files in your browser.

Alternatively, download the repository as a ZIP file and extract it locally.

**That's it. No installation process is required just to read the HTML-based learning material.**

> Important: Opening a lab in your browser provides access to its interface and content. Any activities that require a Linux terminal or other tools must be performed in the appropriate environment.

## `05 // WHO IS THIS FOR?`

Cyber-Labs is for:

- Students taking their first steps into cybersecurity.
- Beginners who want to understand Linux fundamentals.
- Self-taught learners looking for practical starting points.

## `06 // LEARNING PHILOSOPHY`

```text
READ THE CONCEPT.
UNDERSTAND THE COMMAND.
RUN THE ACTIVITY.
OBSERVE THE RESULT.
LEARN WHY IT WORKS.
```

The objective isn't to memorize commands or blindly follow instructions.

It's to develop the technical understanding needed to use tools effectively, troubleshoot problems, and progress towards more advanced cybersecurity topics.

Start small. Practice consistently. Build your foundation.

## `07 // REQUIREMENTS`

- A modern web browser.
- An internet connection for accessing GitHub and downloading the repository.
- A Linux environment for activities that require executing Linux commands.
- A willingness to experiment and learn.

Depending on the activity, a local Linux installation, virtual machine, or suitable Linux environment may be required.

## `08 // RESPONSIBLE USE`

Cyber-Labs is intended for educational purposes.

Practice cybersecurity techniques only on systems you own or have explicit permission to test. Use the material to develop your technical knowledge, improve your understanding of computer systems, and build responsible security practices.

## `09 // THE ROAD AHEAD`

Cybersecurity is a broad field. These labs are a starting point, not the finish line.

As you progress, continue exploring Linux administration, networking, system security, scripting, vulnerability assessment, and defensive security practices.

The fundamentals matter. Build them properly.
